# QuietSearch — Codex 项目规则

本文件是持续开发约束。先读 PROJECT_SPEC.md 和 QUESTION_MARK_UPDATE.md。v1.1 的末尾问号规则取代旧版 AI toggle；名称尚未确认，不自动改名。已有仓库存在 AGENTS.md 时合并规则，不覆盖用户内容。若规范与官方最新 API 不一致，核实并记录差异；不要擅自扩大功能范围。

## 产品

构建简洁的自部署网页搜索工具，不是聊天平台。首页搜索框；结果页搜索框、仅末尾问号触发的顶部 AI 回答、自然结果列表。视觉参考 ChatGPT 的留白和中性色，不使用官方品牌资产。使用本地打包的 Lucide 图标和系统字体。

单仓库、React + TypeScript + Vite + 官方 Cloudflare 插件、单 Worker + Static Assets、普通 CSS、原生 fetch。无数据库、无 Agent、无多供应商插件框架。采用兼容稳定版本并锁定依赖。

## 不可破坏的边界

- AI 唯一触发：用户主动提交的有效输入在去除尾部空白后以 ? 或 ？ 结尾。普通输入只 Search，零 Chat/LLM；不得后台生成再隐藏。无独立常开开关，无语义意图识别，无输入即付费调用。前后端共享解析函数，/api/summary 独立核验原提交文本，重复问号只触发一次，空白/纯问号不发请求。
- 查询快照与来源绑定；新提交取消旧任务并隔离迟到响应。普通搜索隐藏并清除旧 AI 面板；重试仅限该次问号搜索的摘要，不再次 Search。

- 默认 KEY_MODE=byok；密钥只在页面内存，通过同源 HTTPS Authorization 发送；不写任何浏览器持久存储、URL、日志、导出、测试产物。没有用户 Key 时不得回退站长 Key。
- KEY_MODE=server 是可选私人部署模式。DEEPSEEK_API_KEY 只来自 Worker 运行时 Secret，不返回客户端。必须验证 Cloudflare Access JWT 的签名、有效期、issuer、audience；缺失或失败拒绝付费请求。Static Assets 场景不要仅依赖 ctx.access，也不能只检查 header 存在。
- 不存搜索历史，不将搜索词放 URL/页面标题；API no-store；无远程字体、favicon、统计、会话录制或第三方图片。
- 仅调用固定官方 DeepSeek 端点；不接收用户自定义上游地址，不跟随凭证重定向。不转发访客 Cookie/IP 为搜索 localization。
- 搜索结果和模型输出都是不可信文本。不运行 HTML，不使用 dangerouslySetInnerHTML。引用只映射已有结果；不自动访问模型生成的网址。
- 所有请求都在后端校验；限制字节、字段、结果数、输出 tokens、请求时长。CORS/Origin 不是身份认证。近似限流不是严格预算上限。
- 不把密钥、JWT、Cookie 或配置秘密发给模型。默认禁用模型工具和长推理；摘要仅基于来源摘要，不声称已阅读全文。
- 不自动重试付费请求。避免 StrictMode、双击、挂载和流重连造成重复扣费。取消尽可能传递上游，不承诺取消后不计费。
- 不承诺零日志、匿名、零知识、端到端加密或供应商不保存数据。隐私说明必须符合实际网络路径。

## 工作方式

1. 先检查已有文件和 git 状态，不删除用户修改，不输出已有秘密。
2. 阅读规格、核对官方 DeepSeek/Cloudflare 文档，保存 API 契约核对日期。
3. 用少数职责清楚的模块实现，重要取舍记录原因，不为抽象而抽象。
4. 未提供真实 Key 时使用可识别的 fixture/mock，不将假结果混入生产流程。
5. 实际运行类型检查、lint、测试和生产构建；失败需修复，未执行需说明。
6. 截图只使用合成数据和无效测试密钥；不保存真实密钥或搜索内容的 HAR/录屏。
7. 未经授权不发布到外部账号，不发起真实付费 API 请求，不生成付费资源。
8. 不因缺少云账号而停在规划阶段：完成本地实现、mock 测试、构建和部署说明；如实列出待外部验证项目。

## 完成标准

结果先显示、摘要可独立失败；无末尾问号不调用模型；密钥行为与文案一致；手机/深色/键盘可用；默认部署不要求服务器密钥；server 模式认证失败不调用付费上游；README 有普通用户能跟随的部署流程；测试和文档描述真实状态。

最终报告应列出实际改动、实际执行命令及结果、未测事项和必要的人工部署步骤。不要仅给“已完成”的概括，不伪造在线部署、真实 API 联通性或截图。
