# 名称建议（未确认）

首选建议：**WenSeek（问寻）**。

命名思路：Wen 取“问”，Seek 对应寻找，也呼应项目使用的 DeepSeek 服务，但不直接使用完整的供应商品牌作为产品名。产品交互恰好是“平时搜索，加问号后提问”。这是一项命名建议，不是用户已确认的项目改名。

建议呈现：

- 产品名：WenSeek
- 中文名：问寻
- 仓库 basename 候选：wenseek（不是已建立的仓库地址）
- 中文标语：搜索网页，加个问号问 AI。
- 英文标语：Search first. Add a question mark for AI.
- 项目说明：一个基于 DeepSeek API 的轻量自部署搜索界面。
- 关联说明：独立开源项目，非 DeepSeek 官方产品。

较强调轻量感的备选：Seeklet（轻寻）。较强调安静简洁的旧工作名：QuietSearch（静寻）。这些是风格候选，不代表域名、商标、npm 包名或 GitHub 组织名可用。

对部分直观名称做了公开网页初筛：AskSEEK 已是其他公司的产品；Quiet Search 也有已有产品使用。初筛不是商标检索或注册性结论。WenSeek 在本轮检索中未发现明显同名搜索产品，不代表不存在同名项目，也不代表任何域名或商标可注册。
