# 隐私与本地数据

2026-10-22。本文描述当前实现。

## 数据路径

网页搜索：浏览器 → 本实例的 Cloudflare Worker → 所选的 DeepSeek 或 Kagi。AI 回答：浏览器 → Worker → DeepSeek（包含问题和本次最多 6 条来源摘要）。Kagi Key 不发送给 DeepSeek，DeepSeek Key 不发送给 Kagi。BYOK Key 在同源请求 Authorization 头中临时传输；Worker 只将它转给固定官方地址。它并非“永不离开设备”，实例管理员也可以修改后端代码。仅使用自己部署或可信实例。

私人模式另涉及 Cloudflare Access。平台可能依其政策处理服务数据。应用不承诺零日志、匿名、零知识、端到端加密或供应商不保存数据。

## 浏览器保存什么

| 数据                                   | 保存方式                 | 保留与清理                                       |
| -------------------------------------- | ------------------------ | ------------------------------------------------ |
| BYOK Key                               | 当前页面内存             | 刷新、关闭、移除或清除全部后不可沿用             |
| 当前结果/回答                          | 当前页面内存             | 刷新、新搜索或清除全部时移除                     |
| 主题、语言、结果数、搜索引擎、记录开关 | localStorage，固定白名单 | 用户清除或重置                                   |
| 检索词、时间、模式、引擎、状态、结果数 | localStorage             | 默认开启；最多 200 条、30 天；可暂停、删除、清除 |
| 每日本浏览器请求/结果/tokens 数字      | localStorage             | 最多 90 天；可独立清除                           |

原设计包“不存历史”已被用户新要求覆盖。历史不上传服务器，不保存网页内容或 AI 回答，也不跨设备同步。浏览器存储限制时应用继续工作并显示提示。存储不是加密保险箱，同源脚本或设备使用者可能读取记录。关闭记录仅暂停新增，不删除已有记录；共享设备请同时清除。

过期记录在应用读取或更新时清理；应用关闭时无法主动执行清理。浏览器自身恢复页面、扩展、剪贴板和系统行为不受应用完全控制。用户主动复制回答后，清理网站不能清理剪贴板。

## 网络与日志

查询使用 POST，不进入 URL、hash、标题或应用浏览历史路由。API 成功、错误和流式响应设置 no-store。不加载第三方 favicon、字体、图片、统计和会话录制，不自动访问来源 URL。点击外链后目标站仍会收到正常访问数据；链接使用 no-referrer、noopener、noreferrer。

应用不打印 Key、JWT、Cookie、查询、prompt 或原始上游错误。生产 observability 和 Wrangler telemetry 默认关闭，但不代表 Cloudflare 或服务商 没有自身服务日志。防滥用限流会使用边缘访客地址或已验证 Access 身份，不保存 Key 作为计数键。不要公开真实数据的开发日志、截图、录屏或 HAR。

## 用量限制

每日统计是本浏览器观察到的行为，包含失败/取消的应用请求；中断流可能没有 token 报告，不代表免费。多标签页写入不保证原子合并，清理存储和其他设备也会造成差异。供应商账户账单才是费用依据。限流为近似边缘防滥用，不是硬预算。
